# Prompt Website UMKM Kopi Menggunakan PHP Native + Tailwind CSS

Bertindaklah sebagai **Senior Full Stack Web Developer** dan **UI/UX Designer** yang berpengalaman dalam membangun website UMKM modern menggunakan **PHP Native, MySQL, Tailwind CSS, HTML5, JavaScript**, dan prinsip desain yang bersih, cepat, serta mudah dikembangkan.

Bangun sebuah **Website UMKM Kopi** yang memiliki tampilan premium seperti website brand kopi modern. Website harus memiliki desain elegan, pengalaman pengguna (UX) yang baik, performa cepat, SEO-friendly, responsive di semua perangkat, serta mudah dikelola melalui dashboard admin.

## Teknologi

* PHP Native (Tanpa Framework)
* MySQL
* Tailwind CSS (CDN atau Build)
* JavaScript (Vanilla)
* Font Awesome / Lucide Icons
* SweetAlert2
* AOS (Animate On Scroll)

Jangan menggunakan Bootstrap.
